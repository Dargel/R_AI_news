# R_AI_news

Это учебный мини-проект в рамках курса ДПО ВШЭ "Компьютерная лингвистика". 
Цель проекта - оценить данные из ранее собранного датачета, применяя язык R и инстурменты визуализации.

Датасет представляет собой около 1500 публикаций, посвященных теме искусственного интеллекта с сайта Comnews.

Скрипт составлен для решения задач:
1. Выявить, как распределены публикации по дням недели
2. Оценить, как менялось количество публикаций в течение 2022-2024 гг.
